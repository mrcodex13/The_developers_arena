## Key Insight: Near-Perfect Polynomial Fit
The degree-2 polynomial regression achieves R² = 1.000 with residuals near ₹0 (max error ≈ ₹0.007 on prices in the ₹8M–₹54M range). This indicates Price in this dataset is generated by a deterministic (or near-deterministic) formula of the input features rather than containing real-world noise — an important caveat when interpreting "perfect" model performance.

## Insights & Conclusions
- **Area and Location are the strongest price drivers** — confirmed by both linear coefficients and Random Forest importance.
- Rural and Suburb locations command significantly lower prices than the baseline (Urban), all else equal.
- Bedrooms has a positive, non-trivial effect on price independent of area.
- Random Forest is the recommended model for production use on realistic (non-synthetic) house price data, given its strong performance without depending on a deterministic price formula.
- **Best Features:** Area, Location (as expected per assignment target output).
