# Data Dictionary

| Column | Description |
|---|---|
| CustomerID | Unique identifier assigned to each customer |
| Tenure | Duration of customer relationship in months |
| MonthlyCharges | Monthly billing amount |
| TotalCharges | Total cumulative charges over the customer relationship |
| Contract | Customer agreement type |
| PaymentMethod | Method used for payment |
| PaperlessBilling | Whether the customer uses paperless billing |
| SeniorCitizen | Binary indicator showing whether the customer is a senior citizen |
| Churn | Target variable: 1 means churned, 0 means retained |
